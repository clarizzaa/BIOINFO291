# AGENTS.md

All working rules for this repository are in **[WORKSPACE.md](WORKSPACE.md)**.
Read it before taking any action in this project, and follow it without
being reminded.

Summary of the non-negotiables (the full statements are in WORKSPACE.md):

- `data/raw/` is read-only; provenance goes in `data/metadata/SOURCES.md`.
- Every parameter, including random seeds, lives in `configs/*.yaml`.
- Every figure and table is generated by a script in `workflows/`.
- Log consequential choices in `reports/DECISIONS.md` as you make them.
- State the experimental unit; do not treat cells as independent replicates.
- The analysis must rerun end to end from a clean checkout.
